## Intake rules

1. Verify the upstream license and compatibility with this repository before copying code.
2. Record an immutable commit hash, not only a branch or release name.
3. Import the smallest useful component and preserve required copyright or notice files.
4. Document every local file derived from upstream code and the nature of the adaptation.
5. Add focused tests for imported behavior and review the entry whenever the upstream basis changes.

Potential projects discussed during research remain candidates only; see `docs/REUSE-AND-COST.md` for the evaluation record.
